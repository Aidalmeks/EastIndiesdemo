# AI 辅助开发记录

本目录保存与代码变更有关的 AI 协作记录，使需求、Prompt 规范、关键决策和验收结果可由 Git 追溯。

## 记录原则

- 一项可交付工作对应一份 Markdown 记录；文件名使用 `YYYY-MM-DD-主题.md`。
- 原始对话仍可获得时，保留必要的 Prompt、上下文、采纳或拒绝的建议及原因；不复制无关寒暄。
- 原始逐轮对话未保存时，明确标为“追溯记录”，只依据仓库内已有文件、Git 提交和可复现的验证结果记录事实，不补写或伪造 Prompt/回复。
- 每份记录关联需求、变更文件、验证命令/结果和 Git 提交。API Key、个人数据、客户数据及完整私密对话不得提交。

## 新记录模板

```md
# 标题

> 类型：原始对话整理 / 追溯记录
> 日期：YYYY-MM-DD
> 状态：已完成 / 进行中

## 目标与约束

## Prompt 规范与上下文

## 关键决策

## 实施与关联文件

## 验收

## Git 追溯
```
