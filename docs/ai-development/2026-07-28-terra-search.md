## 目标与约束

从约 150 万个候选 pair 中筛出值得进行生产级回测的少数候选。目标不是直接自动下单，也不是仅按图形相似度或 ADF 排名筛选。

关键约束：

- 以 `SBLK/BHP` 作为独立正样本，不能把它的重叠时间窗口视为多个独立样本。
- 候选初筛统一使用日线 close；进入候选注册表后，再补齐 5 分钟数据并按真实执行路径复核。
- 特征必须以 `asof_date` 为界，不能使用其后的数据；交易成本、流动性、可借券和数据质量是硬闸门。

## Prompt 规范与上下文

原始对话没有留存，不能追溯逐字 Prompt 或模型输出。本记录依据现有研究文档与 Git 历史整理，因此不将推测内容表述为当时的 AI 建议。

可复用的任务规范是：先定义数据口径、时间边界和不可违反的交易约束；再区分硬闸门、相似度坐标、排序指标和解释标签；最后使用完全样本外的 Board 回测验证。

## 关键决策

1. 第一版采用“与正样本的结构相似度检索”，而不是在正负样本不足时训练盈利分类器。
2. ADF、协整、Beta、半衰期和 Hurst 等仅覆盖统计关系的一部分；稳定性、可交易性和经济关系必须共同参与筛选。
3. `idealized_continuous_path` 的日线软入场仅用于候选筛选，不能作为实际成交事实或生产结论。
4. `SBLK/BHP` 的仓位级临时退出规则不应自动写回 Terra 的通用训练标签或标准策略。

## 验收

后续实现或修改须至少验证：

- 每个特征值只使用该 `asof_date` 及以前可得的数据。
- 无法覆盖保守往返成本、流动性不足、不可做空或结构断裂的候选不能靠综合分进入结果。
- 候选日线初筛与 5 分钟生产级复核的口径明确分离。
- 结果给出“相似与不相似的维度”，不将其描述为未经验证的盈利概率。
