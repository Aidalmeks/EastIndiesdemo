# 20 日滚动均值的无未来函数导数

目标：对图中每天已经得到的 20 日滚动均值，计算该日相对**前一交易日**的斜率。计算只能使用当日收盘后已知的数据，不能引用未来价格。

## 1. 定义

令 `P_t` 是第 `t` 个交易日的收盘价。使用通常的、向后看的 20 日简单移动平均（SMA）：

```text
M_t = (P_t + P_(t-1) + ... + P_(t-19)) / 20
```

`M_t` 只用到 `t` 日及之前的价格，所以它本身没有未来函数。

## 2. 离散“导数”：当日点减前一日点

日线是一串离散点，严格的微积分导数并不直接适用。将每个点的单位定义为“价格 / 交易日”，最合适的导数是后向一阶差分：

```text
D_t = M_t - M_(t-1)
```

这里 `D_t` 归属于第 `t` 天：到 `t` 日收盘时，`M_t` 和 `M_{t-1}` 都已知。因此完全没有未来函数。

将定义代入：

```text
D_t = (P_t + P_(t-1) + ... + P_(t-19)) / 20
    - (P_(t-1) + P_(t-2) + ... + P_(t-20)) / 20
    = (P_t - P_(t-20)) / 20
```

中间的 19 项逐项抵消。因此手算公式是：

```text
D_t = (P_t - P_(t-20)) / 20
```

它表示：最新进入均线的价格减去刚离开均线的价格，再除以窗口长度。

## 3. 每日可执行的计算规则

在交易日 `t` 收盘后：

1. 取得当日收盘价 `P_t`。
2. 取得 20 个交易日前收盘价 `P_{t-20}`。
3. 计算 `(P_t - P_{t-20}) / 20`。

需要至少 21 个交易日的价格，才能得到第一个 `D_t`；虽然第 20 个价格点已可得到第一个 `M_t`，但还没有前一日的完整 20 日均值可相减。

`D_t > 0` 表示均线向上，`D_t < 0` 表示均线向下，绝对值越大表示均线变化越快。

## 4. Wolfram Language 模板

符号推导：

```wl
Clear[p, t, ma]
ma[t_] := Sum[p[t - k], {k, 0, 19}]/20;
FullSimplify[ma[t] - ma[t - 1]]
(* (p[t] - p[t - 20])/20 *)
```

若 `prices` 是按时间从早到晚排列的收盘价列表：

```wl
rolling20 = MovingAverage[prices, 20];
derivativeDaily = Differences[rolling20];

(* 与上式等价；第 i 个结果对应第 i+20 个价格日（以 1 为起点） *)
derivativeDirect = Table[(prices[[i]] - prices[[i - 20]])/20,
  {i, 21, Length[prices]}];

derivativeDaily == derivativeDirect
(* True *)
```

## 5. 不要混淆的两种“导数”

- 本文的 `D_t = M_t - M_{t-1}`：只用历史数据，适合回测与每日信号。
- 若先把均线点用样条或其他平滑曲线拟合，再对曲线求 `Derivative[1]`：结果取决于拟合方法，而且样条通常会利用邻近的未来点；这不适合作为无未来函数的交易信号。

若绘图时把相邻日线点用直线连接，则在从 `t-1` 到 `t` 的那一段，直线的斜率正好就是 `D_t`。在整数交易日的折点，左右斜率可以不同，因而不存在唯一的普通导数。

## 6. 窗口约定

本文假设的是 trailing / backward 20-day mean，即窗口 `[t-19, t]`。如果原图采用 `center=True` 的居中均线，它会依赖未来数据，不能用于本目标；请改为向后滚动窗口。
